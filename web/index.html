Settings

With a key, searches go straight from this browser to Google using your own daily allowance (about 100 searches). Without one, searches go through the helper. Either way the key and code are saved only in this browser.

How to get a free key
  1. Open console.cloud.google.com and create a project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. Credentials → Create credentials → API key.
  4. Restrict it to YouTube Data API v3.
